# PROFITABLE-TopPRO
Maximiza tus ganancias en plataformas de transporte como Uber o DiDi. TarifaTop analiza las ofertas en tiempo real y filtra o acepta automáticamente solo los viajes que cumplen con tu tarifa mínima por kilómetro, bloqueando zonas no deseadas y largas distancias de recogida. Conduce menos, ahorra gasolina y haz que cada carrera valga la pena.
